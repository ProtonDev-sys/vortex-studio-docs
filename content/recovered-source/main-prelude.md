# Datatype prelude

The Luau definitions loaded for Vortex datatypes and enums.

## Contents

This prelude defines Vector3, Color3, CFrame, EnumType, and EnumItem. The public datatype pages are the easier reference; use the source when you need implementation details.

| Member | Description |
| --- | --- |
| `Vector3` | Construction, arithmetic, fields, Dot, Cross, and Lerp. |
| `Color3` | Normalized RGB construction, equality, string conversion, and Lerp. |
| `CFrame` | Quaternion-backed transforms, constructors, fields, conversion methods, and operators. |
| `Enum` | Enum types, items, values, lookup methods, and validation. |
